# CitationLive

[English](docs/README_EN.md)

CitationLive добавляет голосовой ассистент Gemini Live на колонку. Дополнительно можно подключить Spotify, Google Календарь и Задачи, а также персональную ленту Google News.

Для полной установки запустите `setup.bat` из корневой папки распакованного комплекта. Скрипт сначала запускает эксплойт и включает на колонке сетевой ADB, а затем устанавливает и настраивает CitationLive через это подключение.

## Совместимость

Проект проверен на **Harman Kardon Citation One MK3 (MKIII)**. Исследованный эксплойт связан с сервисом в прошивках Harman/JBL, поэтому аналогичная уязвимость может встречаться на других устройствах с этим сервисом. Совместимость CitationLive с другими моделями зависит от архитектуры и аудиокомпонентов прошивки и требует отдельной проверки. Если CitationLive успешно работает на другой модели колонки, сообщите об этом, создав issue в репозитории.

## Что понадобится

- Распакованный комплект CitationLive с папкой `CitationLive/`, установщиком `citation_tool.py` и файлами для колонки в `CitationLive/dist/`.
- Компьютер с Windows и Python 3.10 или новее. Из PowerShell должна выполняться команда `python --version`. ADB для Windows входит в комплект. Для установки через `citation_tool.py` достаточно стандартной библиотеки Python.
- Колонка и компьютер в одной доверенной локальной сети. IP колонки можно посмотреть в списке устройств роутера.
- Ключ Gemini API из Google AI Studio. Установщик предложит открыть страницу создания ключа в браузере.

## Установка CitationLive

1. Откройте `setup.bat` из корневой папки распакованного комплекта.
2. Выберите язык и следуйте инструкциям установщика. Он сначала включает сетевой ADB с правами root через эксплойт, а затем устанавливает CitationLive.
3. Вставьте ключ Gemini по запросу установщика и укажите город для погоды и местного времени. Оставьте окно открытым, пока колонка перезагружается и установщик проверяет подключение к Gemini Live.
4. После успешной проверки скажите «Окей, Google» и задайте вопрос. Если мастер сообщает, что файлы установлены, но Gemini Live недоступен, проверьте ключ и настройки DNS / прокси в пункте **[8]**.

## Дополнительные настройки

После установки откройте меню командой ниже или снова запустите `setup.bat` из распакованной папки.

```powershell
python .\CitationLive\citation_tool.py run --ip 192.168.1.100
```

| Пункт | Что делает |
| --- | --- |
| **[2]** | Проверяет подключение к колонке через ADB. |
| **[4]** | Переустанавливает или обновляет CitationLive. |
| **[5]** | Подключает Spotify. Подтвердите код, показанный мастером, на странице привязки Spotify. |
| **[6]** | Подключает Google Календарь и Задачи через OAuth. Мастер проведёт через настройку Google Cloud. |
| **[7]** | Управляет персональной лентой Google News, включая проверку и удаление сохранённой сессии. |
| **[8]** | Настраивает DNS / прокси для Gemini. |
| **[10]** | Открывает вход в Google News через Chrome или Edge. При первом запуске мастер предложит установить Playwright. |
