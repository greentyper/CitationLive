# Компоненты CitationLive

[Требования и установка](../README.md)

Папка содержит программу для Harman Kardon Citation One MK3, установщик и файлы для работы колонки. В полном комплекте отдельный компонент включает сетевой ADB. При прямом запуске `citation_tool.py install` сетевой ADB с правами root должен уже работать.

| Путь | Назначение |
| --- | --- |
| `citation_tool.py` | Установка и настройка Gemini, Spotify и сервисов Google. |
| `citation_net.py` | Настройка DNS и прокси для Gemini. |
| `dist/` | Исполняемый файл `citationvoice` и компоненты аудиозахвата. |
| `runtime/` | Скрипты запуска и поддержки аудио, Cast и Spotify. |
| `led/`, `cues/` | Световые и звуковые сигналы. |
| `spotify-connect/` | Клиент Spotify Connect и его настройки. |
| `bin/` | ADB для Windows. |

## Google Календарь и Задачи

В сборке с OAuth-клиентом CitationLive откройте пункт [6], выберите «Войти через Google» и подтвердите в браузере доступ к Календарю и Задачам. Синхронизация продолжит работать после перезапуска колонки. Для установки со своим OAuth-клиентом в том же меню можно выбрать JSON веб-клиента.

Для выпуска со входом через Google владелец репозитория включает Google Calendar API и Google Tasks API в проекте Google Cloud, настраивает экран согласия и регистрирует OAuth-клиент типа Desktop app. В переменных GitHub Actions укажите `CITATION_GOOGLE_DESKTOP_CLIENT_ID` и, если выдан, `CITATION_GOOGLE_DESKTOP_CLIENT_SECRET`, затем запустите `Build CitationLive for ARM`. Эти переменные предназначены для распространяемого Desktop-клиента. Секрет веб-клиента и токены аккаунта в сборку включать нельзя. Для публичного доступа действуют требования Google к публикации и проверке приложения.
