# Безопасность

Исследование проводилось на **Harman Kardon Citation One MK3 (MKIII)**. Уязвимость связана с сервисом в прошивках Harman/JBL. Наличие этого сервиса на другой модели само по себе не подтверждает, что её прошивка уязвима.

На проверенной колонке сетевой ADB даёт root-доступ без аутентификации любому, кто может подключиться к TCP-порту 5555. Держите колонку в доверенной сети, без проброса порта 5555 из интернета. Когда сетевой ADB больше не нужен, откройте PowerShell в распакованной папке проекта и выполните команды из действующего ADB-подключения.

```powershell
.\CitationLive\bin\adb.exe -s 192.168.1.100:5555 shell rm -f /data/network_adb
.\CitationLive\bin\adb.exe -s 192.168.1.100:5555 reboot
```

Подставьте IP своей колонки. После перезагрузки проверьте, что порт 5555 закрыт.

Для персональной ленты Google News используется отдельная сохранённая сессия. Её можно удалить через **[7] Google News → [4] Удалить сохранённую сессию**.
